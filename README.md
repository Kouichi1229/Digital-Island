# DigitalIsland

AI Autonomous Life Simulation

## Project Structure

- client: React + TypeScript + Vite
- server: Express + TypeScript
- database: SQLite storage
- assets: Game resources
- docs: Development documentation

## Development Goals

Build an autonomous digital creature that can:

- Explore its environment
- Maintain basic survival needs
- Observe and interact with the world
- Develop memories and behavioral preferences
- Make autonomous decisions using a local LLM
